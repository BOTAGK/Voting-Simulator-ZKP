# ZKP Voting Simulator

Educational voting simulator built with Python, FastAPI, SQLite and Circom/snarkjs.

## Local run

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
RUN pip install -r requirements.txt 
.\scripts\run_app.ps1
```

Healthcheck:

```text
http://127.0.0.1:8000/api/health
```
